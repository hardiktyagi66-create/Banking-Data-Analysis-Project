# Banking Customer Behavior and Financial Performance Analysis

##  Project Overview
This project focuses on analyzing banking data to understand customer behavior, transaction patterns, loan performance, and complaint trends.

##  Objective
- Understand customer behavior  
- Analyze transactions  
- Monitor loan performance  
- Identify high-value customers  

##  Tools & Technologies
- Python (Pandas, NumPy)  
- SQL  
- Power BI  

##  Project Workflow
1. Data Cleaning using Python (handled null values, duplicates, data types)  
2. SQL Analysis using JOIN, UNION, GROUP BY to create KPIs  
3. Power BI Dashboard creation with data modeling, DAX, and visualization  

##  Dashboards
- Customer Overview  
- Accounts Analysis  
- Transaction Analysis  
- Loan & Loan Payment Analysis  
- Complaints Analysis  

##  Key Insights
- Identified high-value customers  
- Observed transaction growth and payment modes  
- Analyzed loan repayment trends  
- Monitored complaint resolution status  

##  Dataset
Synthetic banking dataset with 6 tables:
Customer, Account, Transaction, Loan, Loan Payment, Complaints

##  Future Scope
- Customer segmentation (RFM)  
- Predictive analysis  
- Real-time dashboard integration
